Model methodology

Matches are replayed chronologically. For each historical T20I, the model uses only prior matches to rate the actual XIs, then trains a regularized logistic model and calibrates it on a separate validation window. The reported results are from the final chronological holdout, while the Elo baseline is shown for comparison.
